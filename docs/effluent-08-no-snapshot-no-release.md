# effluent-08 无快照禁准裁决说明（2026-11-25 锁死）

## 背景

准排册已有正式行 SM-H08（排污辛第8槽），最新封批快照却缺失，对账页仍标
已准排齐套。预置夹具复现：SM-H08（已准排、无快照）、SM-X8-A-002（已裁定、
无快照却能准排）、许可 DP-2026-X08（同许可他批已封批，旧口径 seal_count>=1
即误亮齐套）。

## 正确性口径

封批快照齐套与准排写口两边不得混用：

- **齐套（对账读口）**＝许可在管批次（已裁定/已准排/已封批）逐批持有当前代
  最新封批快照；齐套灯不得单凭准排行点亮。
- **准排（写口）**＝仅当采样批次持有最新封批快照（`seal_svc.snapshot_ok`）
  才允许写正式册 `discharge_releases`。

## 裁决：甲路径（锁死 2026-11-25）

最新封批快照缺失时：

1. 准排整笔回退，正式册 `discharge_releases` 零增；
2. 偏离记 audit「无快照禁准偏航」并拒写（HTTP 409）。

不采用乙路径（准排先写影子意图再原子升正），第三路不要。混用会让无快照
仍出正式准排。偏离本说明者记「无快照禁准偏航」并拒写。

## 争用

两路会话同批同时抢准排须占准排锁（`sample:{id}`，占锁即提交，对其他会话
立即可见）；后到只记争用痕（`contention_log`「争用失败」，随 409 一并提交）
不写准排，败方零行。并发脚本：`python scripts/ping_release_snap_lock.py`。

## 五页同源

准排页、封批页、对账页、采样页、总览页同读 `seal_svc.snapshot_ok` 口径：

- 准排页：缺封批快照时准排按钮禁用；
- 封批页：列缺最新快照批次，封批行标注是否最新代；
- 对账页：齐套灯不凭准排行点亮，列缺快照数；
- 采样页：批态与快照代次对齐（当前代 vs 快照代）；
- 总览页：缺快照警告与封批服务一致（同源判据计数）。

## 失败测链（先红后绿）

- `tests/test_effluent_08_yi.py`：对账把影子意图误记齐套 → 对账服务救绿；
- `tests/test_effluent_08_zheng.py`：两路同批准排无锁 → 锁与准排服务救绿。
